03. Projects

Here are some of the projects I have built and worked on.

Python Result Scraping

Automated Results Scraper & Rank Generator is a Python-based automation tool that collects student results from a website using hall ticket ranges, extracts marks using web scraping, and generates structured Excel reports. It also calculates total scores and produces a rank-wise sheet for all students.

Figma Secure Gate

Secure Gate is a UI/UX mobile app design that streamlines food delivery verification in gated communities using an OTP-based system. Residents, delivery agents, and security guards receive the same OTP for quick and secure access, reducing delays and improving security. Designed in Figma.

Python Text Editor

Python Tkinter Text Editor is a lightweight desktop application developed using Python’s Tkinter library. It provides basic text editing functionality including creating, opening, editing, and saving files. The application supports keyboard shortcuts for improved usability and features a custom dark-themed interface for a modern user experience.

Python Slot Machine

A Python-based command-line slot machine game where users can deposit money, place bets on multiple lines, and spin random symbols. The game includes balance tracking, payout calculations, and win detection to create an interactive casino-style experience through a simple terminal interface.

Python Port Scanner

A Python-based network port scanner that checks whether specific ports are open or closed on a target IP address or domain. It allows users to input a single port or a range of ports and resolves domain names to IP addresses automatically. The tool uses socket connections to test port availability and provides quick scan results in the terminal.
